# API Routes

See `docs/src/app/api.md` for the current API route map.

RB-050 adds project/image metadata APIs, RB-051 adds default slice/support APIs, RB-052 adds minimal review/approval APIs, RB-053 adds project training export readiness/creation plus app-mediated export downloads, RB-056/RB-057 add prediction provenance/import APIs, RB-058 adds active-learning correction task APIs, RB-059 adds assisted correction context/read/save APIs, RB-060 adds separate prediction-analysis export APIs, RB-061 adds ZIP batch prediction import APIs, RB-065 adds bounded batch process-due worker API support, RB-066 adds admin-only storage cleanup dry-run/execute API support, RB-067 adds QA metric fields to prediction-analysis export/readiness responses without adding new routes, RB-086 adds source-image BBox proposal APIs under `/api/images/[imageId]/slice-bboxes` and `/api/slice-bboxes/[bboxVersionId]`, and RB-087 adds derived slice crop APIs under `/api/images/[imageId]/slice-crops`, `/api/slice-bboxes/[bboxVersionId]/crop`, and `/api/slice-crops/[cropId]`.
