# Components

Generic reusable primitives live in `src/components/ui`.

Application shell components live in `src/components/shell`.

Feature-specific components live in `src/features`.

Current active ownership:

- `src/components/ui/button.tsx`, `dialog.tsx`, `input.tsx`, `label.tsx`, `scroll-area.tsx`, `select.tsx`, `slider.tsx`, `tabs.tsx`, `textarea.tsx`, `tooltip.tsx`, and `utils.ts`.
- `src/components/shell/*` for authenticated workspace layout patterns.
- `src/features/projects/*`, `src/features/images/*`, and `src/features/editor/*` for workflow-specific UI.
