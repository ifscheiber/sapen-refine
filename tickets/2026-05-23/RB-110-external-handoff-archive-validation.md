## Context

The archive reviewed by ChatGPT contained `.env`, `.env.local`, and `.git`. The current repo does not track those env files, and the repo's handoff archive script excludes them. The remaining gap is validating arbitrary ZIP files that bypass the script.

## Goal

Provide a validator for externally supplied or manually created handoff archives.

## Non-Goals

- Do not print or expose secret values found inside archives.
- Do not change production app code.
- Do not replace `npm run handoff:archive`; keep it as the preferred creation path.

## Requirements

- Add a script such as `scripts/validate-handoff-archive.mjs`.
- Validate a given ZIP path and fail on forbidden paths:
  - `.env`, `.env.*` except examples,
  - `.git`,
  - `node_modules`,
  - `.next`, `out`, `build`, `dist`,
  - test reports, traces, screenshots, videos,
  - local database/storage volumes,
  - logs and tsbuildinfo files.
- Reuse exclusion logic from `scripts/create-handoff-archive.mjs` where practical.
- Add a package script.
- Update `docs/operations/handoff-zip-checklist.md`.
- Add tests for allowed `.env.example` and rejected real env/git paths.

## Acceptance Criteria

- Validator fails on archives containing forbidden paths.
- Validator passes on archives produced by `npm run handoff:archive`.
- Output lists forbidden path names without dumping file contents.
- Handoff checklist tells operators when to run the validator.

## Validation

Run:

```bash
git status --short
npm run lint
npm run typecheck
npm run test
npm run handoff:archive -- --dry-run
```
